---
title: "Quickstart"
description: "Get your first mvc-php application running in minutes."
---

This guide walks you through cloning the framework, installing dependencies, configuring your environment, and serving your first route.

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/dogiloki/mvc-php my-app
    cd my-app
    ```
  </Step>

  <Step title="Install PHP dependencies">
    Requires PHP `<=8.1.31` and [Composer](https://getcomposer.org).

    ```bash
    composer install
    ```
  </Step>

  <Step title="Create your environment file">
    Copy the example env file and fill in your values:

    ```bash
    cp config.env.example config.env
    ```

    At minimum, set `APP_NAME`, `APP_KEY`, and your database credentials:

    ```ini
    APP_NAME=my-app
    APP_KEY=your-secret-key
    APP_HOST=localhost
    APP_DEBUG=true

    DB_HOST=localhost
    DB_PORT=3306
    DB_USER=root
    DB_PASSWORD=secret
    DB_DATABASE=my_app
    ```

    <Note>
      `config.env` is parsed by `libs/Env.php` at boot time via `Env::singleton("config.env")` in `libs/helpers.php`. Values are stored in `$_ENV` and accessed through the `env()` helper.
    </Note>
  </Step>

  <Step title="Point your web server at the public directory">
    The document root must be `public/`. All requests are rewritten to `public/index.php` by the included `.htaccess`.

    **PHP built-in server (development only):**

    ```bash
    php -S localhost:8000 -t public
    ```

    **Apache virtual host:**

    ```apacheconf
    <VirtualHost *:80>
        DocumentRoot /path/to/my-app/public
        ServerName localhost

        <Directory /path/to/my-app/public>
            Options Indexes FollowSymLinks
            AllowOverride All
            Require all granted
        </Directory>
    </VirtualHost>
    ```

    <Tip>
      A ready-to-use `docker/apache/default.conf` ships with the project and is used automatically by the provided Dockerfile.
    </Tip>
  </Step>

  <Step title="Create your first route">
    Open `routes/web.php`. The file already contains a root route that renders the `home` view:

    ```php
    <?php

    use libs\Router\Route;

    Route::get('/', function() {
        return view('home');
    })->name('home');
    ```

    Add a "Hello World" route below it:

    ```php
    Route::get('/hello', function() {
        return 'Hello, World!';
    })->name('hello');
    ```

    Visit `http://localhost:8000/hello` and you should see **Hello, World!**.
  </Step>

  <Step title="Add a controller route">
    Routes can also dispatch to a controller method using the `ControllerClass@method` syntax:

    ```php
    Route::get('/hello/{name}', 'HelloController@show')->name('hello.show');
    ```

    Create `app/Controllers/HelloController.php`:

    ```php
    <?php

    namespace app\Controllers;

    class HelloController extends Controller
    {
        public function show($request)
        {
            $name = $request->name ?? 'World';
            return 'Hello, ' . htmlspecialchars($name) . '!';
        }
    }
    ```

    Visit `http://localhost:8000/hello/Alice` — the route parameter `{name}` is injected into `$request->name`.
  </Step>
</Steps>

## What happens at boot

When a request arrives at `public/index.php` the framework:

1. Changes the working directory to the project root (`chdir("../")`).
2. Loads Composer's autoloader and `libs/helpers.php`, which parses `config.env`.
3. Instantiates `app\Kernel`, which runs all registered services (middleware, routing, etc.).
4. Calls `Route::controller()`, which matches the incoming URI against registered routes and dispatches to the closure or controller method.

```php
// public/index.php
require_once "vendor/autoload.php";
require_once "libs/helpers.php";

use app\Kernel;
$kernel = new Kernel();

use libs\Router\Route;
Route::controller();
```
